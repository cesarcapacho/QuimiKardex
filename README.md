# 🧪 QuimiKardex

**Sistema de gestión de inventario químico con registro de reactivos, movimientos tipo Kardex, y visualización de stock en tiempo real.**  
Desarrollado con enfoque en buenas prácticas, escalabilidad y facilidad de uso.

---

## 🗂️ Estructura del Proyecto

```
QuimiKardex/
├── lib/              # Utilidades y pictogramas
├── pages/            # Vistas principales (Dashboard, Login, etc.)
├── assets/           # Recursos estáticos (imágenes, íconos, estilos)
└── main.jsx          # Punto de entrada principal
```

---

## ⚙️ Instalación Local

```bash
# 1. Clona el repositorio
git clone https://github.com/cesarcapacho/QuimiKardex.git
cd QuimiKardex

# 2. Instala las dependencias
npm install

# 3. Inicia el entorno de desarrollo
npm run dev
```

---

## 🌐 Despliegue en Producción

Este proyecto está desplegado automáticamente mediante Vercel.  
Cada cambio en la rama `main` activa un proceso de **build** y actualización continua.

🔗 **URL del despliegue:** [https://quimikardex.vercel.app](https://quimikardex.vercel.app)

---

## 📌 Funcionalidades Clave

- 📋 Registro y edición de reactivos con pictogramas personalizados.
- 🔄 Movimientos tipo Kardex por fecha y cantidad.
- 📊 Resumen dinámico del inventario con filtros avanzados.
- 🔐 Arquitectura preparada para autenticación de usuarios.
